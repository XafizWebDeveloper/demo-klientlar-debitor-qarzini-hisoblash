# B2B Sales & Debt Analyzer 🚀

**Инструмент для автоматизации работы менеджеров и мгновенного анализа дебиторской задолженности B2B клиентов.**

## 🎯 О проекте
Забудьте о рутинной проверке огромных Excel-таблиц. **B2B Analyzer** — это веб-приложение, созданное для того, чтобы сэкономить часы работы торговых представителей, бухгалтеров и руководителей отделов продаж. Программа за считанные секунды обрабатывает выгрузки из учетных систем, анализирует сроки оплат и формирует готовые отчеты по проблемным задолженностям.

*💡 Если вашей компании нужен похожий инструмент для оптимизации бизнес-процессов — вы знаете, к кому обратиться!*

## 🔥 Какую проблему это решает?
В оптовых B2B продажах контроль дебиторской задолженности часто превращается в хаос:
- Менеджеры тратят часы на ручное сведение Excel-отчетов.
- Клиенты с просроченной оплатой теряются в массивах данных.
- Человеческий фактор приводит к финансовым потерям.

**B2B Analyzer** решает это в 2 клика: загрузите файлы — получите четкий результат.

## ✨ Ключевые возможности
- ⚡ **Мгновенный анализ:** Обработка базы до 20,000 строк всего за ~40 секунд.
- 🎯 **Умная детекция:** Автоматическое выявление клиентов с нарушенными сроками оплаты.
- 📥 **Мульти-загрузка:** Одновременная обработка нескольких Excel файлов (`.xls`, `.xlsx`).
- 📄 **Генерация отчетов:** Выгрузка готовых результатов в формат Word одним кликом для отправки руководству.
- 🛡️ **Гибкая фильтрация:** Настройка "белых списков" клиентов (игнорирование определенных контрагентов).
- 🔒 **Безопасность данных:** Вся обработка происходит прямо в браузере клиента. Конфиденциальные данные никуда не отправляются.

## 🚀 Как это работает?
1. Перетащите Excel-файлы с данными о продажах в окно программы.
2. Нажмите **"Таҳлилни бошлаш"** (Начать анализ).
3. Алгоритм моментально сопоставит даты отгрузок, суммы и разрешенные сроки кредитования.
4. Готовый список должников с детальным описанием проблемы появится на экране.
5. Скачайте документ Word для дальнейшей работы.

## 🛠 Стек технологий
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (без тяжелых фреймворков для максимальной скорости).
- **Библиотеки:** `SheetJS` (работа с Excel), `docx.js` (генерация Word документов).
